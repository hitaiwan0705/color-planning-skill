# 課程 profile：色彩規劃與傳播應用

## 基本資料與待確認項

- 學期：115-1（依老師目前指定的課程路徑建置）。
- 開課單位：中國文化大學資訊傳播學系（依 repo `CONTEXT.md` 已確認事實）。
- 年級與性質：大三上必修（依 repo `CONTEXT.md` 已確認事實）。
- 學分、每週時數、班級人數、實際授課場地：待確認。
- 設備：僅使用 repo `CONTEXT.md` 已確認項；燈箱型號／等級、螢光燈管、Mimaki 白墨／clear 狀態仍待核對。
- 學期結構：16 週授課 + W17-W18 自主學習，不到校上課。

## 課程主體

本課研究「色彩如何在不同媒介、平台與生產條件中成為訊息」。學生不只學會配色，而要能解釋並規劃：色彩如何引導注意、建立層級、喚起情緒、標示身分、形成品牌辨識、支援可近用性、影響信任與說服，以及在螢幕、印刷、包裝、空間與平台之間如何改變或失真。

課程的媒體物質性包括光源、顯示器、紙張、油墨、色票、相機、量測儀器、ICC profile、檔案格式、軟體設定、印刷與輸出流程。色彩科學、心理學、AI、設計與行銷是支援學生回答傳播問題的方法，不是課程主體。

## 能力群

- 主能力：B 視覺傳達、色彩與資訊表現能力。
- 次主能力：D 跨域設計思考、專案管理與行銷企劃能力。
- 支援能力：A HCI／UX 與互動介面、C 傳播倫理／文化／媒體素養、E 研究實作與作品集。

## 核心知識領域

1. 色彩形成與觀看條件：光、物體、觀察者、情境。
2. 色彩描述與轉譯：三屬性、色彩系統、色名與色碼。
3. 媒介與製程：RGB／CMYK／CIELAB、裝置相依、ICC、螢幕—印刷—空間。
4. 知覺與意義：對比、同化、注意、情緒、文化、可近用性。
5. 色彩規劃：閱聽人、訊息目標、接觸點、色彩治理、驗證與修正。

## 研究角色

現階段只規劃教學回饋，不啟動研究資料蒐集。若老師決定發展教學實踐或期刊研究，須先完成知情同意、退出機制、匿名代碼、1–7 量表 codebook 與 raw/clean 分層；學生作品、影片與截圖再使用需另行同意。

## 特別審查角色

- 資訊傳播審查者：檢查色彩是否真的服務訊息、媒介、平台與閱聽人問題。
- 色彩科學／色彩管理專家：檢查術語、標準、量測與再現條件。
- 視覺傳達／品牌實務者：檢查規劃能否轉化為可執行的跨媒體系統。
- 無障礙與倫理審查者：檢查色覺差異、對比、文化刻板印象與素材授權。
- 大學生 persona：檢查先備知識、工作量、活動指令與回饋可理解性。

## 已知風險

- 把課程寫成一般色彩學、純美感配色或 iPAS 考照班，抽掉傳播情境後仍成立。
- 把 RGB／CMYK 當成固定數值對應，忽略設備、光源、紙材與 profile。
- 把顏色—情緒或文化意義寫成普遍且決定性的因果。
- 使用未授權的考題、學生作品、影片、品牌圖片或網路案例。
- 把 AI 生成色盤視為客觀答案，忽略訓練資料、介面預設與輸出媒介。
