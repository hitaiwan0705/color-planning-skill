## 這一週在解什麼問題

你們已經修過色彩學與色彩度量學。那兩門課回答的是「顏色是什麼」。
這門課回答的是另一個問題：

> **你說的那個顏色，換一台機器、換一種紙、換一盞燈之後，還是同一個顏色嗎？
> 你憑什麼證明？**

這是產業每天在賠錢的問題。設計師在螢幕上核准的顏色，印出來不對；
品牌手冊寫了色票編號，三家廠商做出三種顏色；電商照片的商品色和實物不符，退貨。
這門課要交出來的不是「好看的作品」，是**能證明的顏色**。

### 因此這門課的交件方式和你過去的課不一樣

大部分設計課交「作品」。這門課交**證據**。

| 你交的 | 這門課接不接受 |
|---|---|
| 一張很好看的版面 | 不夠。憑什麼說這個藍是這個藍？ |
| 一張版面 + 色票清單 + 色彩空間宣告 + profile 版本 + 量測檔 | 可以。這才叫可交接 |
| 「我覺得這樣比較協調」 | 不接受。這是偏好，不是判準 |
| 「量測後 ΔE00 超過門檻，我改了這三處，改後數值如下」 | 這就是本課要的 |

**理由很現實**：你畢業後把檔案交給印刷廠、交給客戶、交給下一屆的專題組員，
對方要的就是這些欄位。交不出來，你的顏色就只能重做一次。

## 這門課的六層結構

本課把「顏色能不能被證明」拆成六層，每一層都有各自的判準：

| 層 | 在問什麼 | 大約在第幾週 |
|---|---|---|
| 1 色彩知覺 | 人為什麼這樣看見顏色 | W04、W10–W12、W14 |
| 2 色彩表徵 | 如何以可交換的數值描述顏色 | W03 |
| 3 色彩意象 | 如何把抽象意象轉譯成色彩指定 | W04 |
| 4 色彩量測 | 如何證明兩色相同或不同 | W06、W15 |
| 5 色彩管理 | 如何讓不同裝置盡量一致 | W07、W08 |
| 6 虛實輸出 | 數位設計如何可靠轉成實體 | W13、W15、W16 |

**主線只有一條**：CIE XYZ → CIELAB／LCh → ΔE → ICC。
Pantone 是產業溝通與色票指定的工具，不是色彩科學的起點——
這一點在 W03 會講清楚為什麼。

## 一條龍：這學期你會真的走完一次

本課的九個設備站，跨越整個學期：

```
S1 色票登錄 ──▶ S2 顯示器校正 ──▶ S3 指定工作色域 ──▶ S4 軟打樣
   W03            W07               W07                W08
        （期中 iPAS 考試）
S5 媒材描述檔 ──▶ S6 第一次輸出 ──▶ S7 燈箱觀察 ──▶ S8 儀器量測 ──▶ S9 修正再輸出
   W13             W13              W15             W15            W16
```

**每一站都必須產出一個檔案，交給下一站用。** 沒有產出檔的站等於沒做，
因為沒有人能查核它。

期中之後，你觀察的對象就是**你自己印出來的那張樣本**——
不是課本上的圖，不是老師準備的色票。你會對著自己的輸出量、看、改、再印一次。

### 後半五站以「跑站」進行

W13、W15、W16 三週在實驗室，**分組輪流進站**，每站當場簽核，
記錄站別、日期、組別代碼。**簽核計入參與分。**

簽核證明你「做過」，**不證明你「做對」**——做對與否由期末交件的證據判定。
沒有簽核的站，該站的產出檔不被採認；有簽核卻交不出產出檔，該站仍算未完成。

## 先修診斷（不計分）

今天發一份診斷題。**不計分、不記錄、不影響任何成績**，
唯一用途是決定 W02 與 W05 兩場客座複習要講多深。

診斷涵蓋六個點：

1. 光源、物體、視覺系統三者與顏色的關係
2. 加法混色與減法混色的差別
3. 表色體系：孟塞爾的三個維度分別是什麼
4. CIE xy 色度圖上，白點與光譜軌跡各代表什麼
5. 色差公式有很多個版本，你聽過哪些
6. 「顯示器校色」你做過嗎？做的是什麼

寫不出來完全沒關係——**這正是診斷要抓的資訊**。
猜答案反而會害到你自己：客座會因此跳過你其實需要的內容。

## AI 使用揭露規則

本課允許使用 AI 工具，但**每一件交付物都必須附 AI 使用揭露**。

揭露要寫三件事：

1. 用了哪個工具做哪一段（例如：用 LLM 產生候選意象詞彙）
2. 你如何查證它的輸出（例如：文化語境的主張改用哪個來源核對）
3. 哪些部分是你自己做的

**不揭露即為未通過**，不是扣分。理由：本課要的是可追溯的證據鏈，
而來源不明的內容無法追溯。

**特別提醒**：AI 生成的內容**不得作為事實來源**。
LLM 會產生看起來很像規格條文的句子。查不到出處的主張，一律標記為未查證，
不要寫成肯定句。
