## 本週學習目標

完成本週後，你應能：

1. 分開說明實體光源、標準照明體、相關色溫與光譜功率分布。
2. 比較分光光度儀與色度計可提供的資料與限制。
3. 讀取量測設定，指出照明體、觀察者、量測幾何、校正與樣本條件是否齊全。
4. 說明 XYZ、CIELAB 與 CIEDE2000 在「量到—表示—比較」鏈路中的角色。
5. 將量測結果連到商品色、品牌色或資訊辨識的驗收問題。

## 知識群與關鍵詞

| 知識群 | 關鍵詞 |
|---|---|
| 光與照明 | SPD、光源、標準照明體、CCT、D50、D65 |
| 儀器原理 | 分光光度儀、色度計、濾鏡、波長、校正 |
| 量測條件 | 45°/0°、d/8°、鏡面成分、樣本底材、重複性 |
| 色彩度量鏈 | CIE XYZ、CIELAB、參考白、CIEDE2000、ΔE00 |
| 傳播驗收 | 參考色、容差、媒介條件、可追溯性、再現 |

## 這一週在解什麼問題

> **當設計師、客戶與製造端對顏色各有說法時，什麼樣的量測紀錄足以讓第三者重作判斷？**

量測不是「機器讀出一個數字」。它是在明確條件下取得資料，再用指定模型表示。
條件缺漏，同一個數值就可能被錯誤比較；數值沒有連到傳播功能，也無法決定是否需要重做。

本週原規劃可由客座講者授課；若客座未成行，授課教師依本講義即可完成同一組目標與證據。

## 一、光源、照明體、SPD 與 CCT

- **光源（light source）**是實際發光的物體或裝置。
- **光譜功率分布（spectral power distribution, SPD）**描述不同波長上的能量分布。
- **標準照明體（standard illuminant）**是標準化計算用的光譜分布，不等同某一盞實體燈。
- **相關色溫（correlated colour temperature, CCT）**描述光色接近的黑體軌跡位置，
  不能代表完整光譜，也不能保證兩個相同 CCT 的光源具有相同 SPD。

傳播後果很直接：兩盞看似同樣「冷白」的燈，可能讓商品色、膚色或包裝對比呈現不同。
所以紀錄只寫「白光」或「色溫相同」不足以支持色彩再現結論。

## 二、分光光度儀與色度計

| 面向 | 分光光度儀 | 色度計 |
|---|---|---|
| 主要資料 | 分波段光譜資料 | 經濾鏡響應得到三刺激相關訊號 |
| 適合問題 | 光譜形狀、指定條件下換算色度值 | 特定用途下快速取得色度或亮度相關數值 |
| 重要限制 | 波段、幾何、校正與樣本條件影響結果 | 濾鏡匹配與光源光譜影響裝置間一致性 |
| 本課紀錄 | 保留原始量測檔，再產出 XYZ／Lab／ΔE00 | 若使用，須另記型號、用途與輸出條件 |

儀器名稱不代表設定相同。實際操作要從軟體或官方文件確認模式、量測口徑、
校正狀態與輸出格式，不可從外觀猜測量測幾何。

## 三、量測幾何、校正與樣本條件

45°/0°、0°/45°、d/8° 等寫法描述照明與接收的幾何關係。不同幾何對表面紋理、
光澤與鏡面反射的處理不同，因此同一張紙或塗層可能得到不同結果。

不要背「哪一個一定比較準」。要問：參考值用什麼幾何取得？本次目的要包含或排除光澤？
兩批資料的幾何是否相同？不同幾何的 Lab 值不能直接排在一起宣稱產品變色。

| 欄位 | 應記錄內容 |
|---|---|
| 樣本 | 編號、材質、表面、厚度或底材、量測位置 |
| 儀器 | 製造商與型號、模式、口徑或附件（若適用） |
| 幾何 | 由儀器或官方文件確認的量測幾何 |
| 計算條件 | 照明體、標準觀察者、色彩空間、公式版本 |
| 校正 | 校正方式、時間與結果 |
| 重複量測 | 次數、原始讀值、平均與異常處理理由 |

## 四、XYZ、CIELAB 與 CIEDE2000 的角色

1. 儀器在指定模式下取得光譜或三刺激相關資料。
2. 指定照明體與標準觀察者後得到 CIE XYZ。
3. 相對於參考白轉換為 CIELAB，描述 L\*、a\*、b\*。
4. 用指定色差公式比較兩組資料；本課採 **CIEDE2000（ΔE00）**。

「ΔE」不是完整名稱。CIE76、CIE94 與 CIEDE2000 的數值不可混用；報告要寫明公式版本。
色差值只描述指定條件下的差異，不能單獨證明閱聽人會注意、辨識或接受。

## 五、把色差變成傳播驗收

量測報告要從傳播功能反推：品牌主色跨批次變動是否影響貨架辨識？警示色在背景與照明
改變後是否仍能區分？電商照片與實物差異會造成何種期待落差？數值有差但實際距離難察覺時，
是否仍需重製？

容差不是通用常數。若沒有客戶規格、產業標準或經驗資料，應把門檻寫成待驗證假設，
說明用途與風險，而不是發明數字。

## 失敗條件

- 只記 Lab 或 ΔE00，未記儀器、幾何、照明體、觀察者與樣本 → 數值不可比較。
- 將實體光源與標準照明體寫成同一件事 → 條件描述退回修正。
- 用相同 CCT 推定兩個光源具有相同 SPD → 結論不成立。
- 色差未標 CIEDE2000，或混用不同公式數值 → 該數值不採計。
- 只根據數值宣稱傳播成功，未說明閱聽人、媒介與功能 → 驗收結論不成立。

## 本週重點整理

1. 光源是實體，標準照明體是計算定義；CCT 相同不代表光譜相同。
2. 儀器輸出必須連同型號、模式、幾何、校正與樣本條件保存。
3. XYZ、CIELAB 與 CIEDE2000 分別服務表徵、感知尺度與差異計算。
4. 色差公式要標示版本；本課採 CIEDE2000（ΔE00）。
5. 數值只有連到傳播功能、驗收情境與限制時，才支持生產決策。
