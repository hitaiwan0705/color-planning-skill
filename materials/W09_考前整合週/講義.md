# W09｜考前整合週（客座③備用）

## 這一週在解什麼問題

考科把知識分成色彩學、色彩計畫實務與色彩管理；真實傳播任務卻要求三者在同一條決策鏈上協作。本週把已完成的交付物重排成「問題—條件—判斷—證據—限制」，找出不能由課內證據回答的缺口。

---

## 1. 三科不是三個孤島

| 問題 | 色彩學證據 | 計畫實務證據 | 色彩管理證據 |
|---|---|---|---|
| 這組色如何被表徵？ | XYZ、Lab、LCh 與知覺條件 | token 與色票 ID | profile 與工作色域 |
| 為何選這組色？ | 可視度、對比與知覺限制 | 意象、受眾、替代色排除 | 色域外與跨媒體風險 |
| 跨設備後發生什麼？ | ΔE00 與觀察差異 | 是否仍傳達原定訊息 | 來源／目的 profile、intent、軟打樣 |

複習時，每個答案至少指出一個可交付證據。只會說術語、拿不出資料或條件，仍不能交接給下一位製作者。

## 2. 主線自我檢查

用自己的樣本口頭走一遍：

`CIE XYZ → CIELAB／LCh → ΔE00 → ICC 來源與目的 profile → 軟打樣 → 色域映射決策`

每個箭頭回答兩題：「輸入是什麼？轉換後失去或改變了什麼？」Pantone 若出現，放在產業指定與色票溝通層，不放在這條科學推導的起點。

## 3. 五個常見斷點

1. RGB 有數值卻沒有 profile。
2. Lab 有數值卻沒有照明體、觀察者或量測來源。
3. ΔE 有數字卻沒有公式版本與比較兩端。
4. 軟打樣有截圖卻沒有目的 profile 與 intent。
5. 意象有形容詞卻沒有受眾證據與替代色排除理由。

同儕交換 evidence pack，只圈出能從檔案重做判斷的項目；不要替對方補猜測。

## 4. 自習清單：本課考前的兩個壓縮區

### 影像色彩處理與應用

自查輸入 profile、raw／rendered image 差異、白平衡、tone curve、轉換與輸出嵌入 profile。練習從一張影像找出「捕捉、編輯、顯示、輸出」四段各自的色彩條件。

### 基礎光電色彩

自查顯示器發光、像素／次像素、加法混色、光譜功率分布、色度計與分光量測的差異。能指出「數位值相同」為何不保證不同顯示器有相同光譜或外觀。

這兩區為自習補強，不宣稱等同完整實作課。iPAS 範圍與報考資訊以 [官方色彩規劃管理師頁面](https://ipd.nat.gov.tw/ipas/CPM/)最新文件為準。

## 5. TASK-05 收件與修復單

TASK-05 本週到期。若缺 profile、安裝證據或工作色域，提交一張修復單，逐項寫出缺檔、補作動作、責任人與完成狀態。修復單不取代原交付物。

## 本週交付

- 一張三科—交付物—證據位置對照表
- 一次主線口頭稽核，由同儕記錄五個箭頭的輸入與限制
- 一份影像色彩處理與基礎光電色彩自習檢核表
- TASK-05 完整交件；若缺項，另附修復單

## 失敗條件

- 只列考科名詞，沒有連到自己的檔案、數值或設定紀錄
- 把自習清單寫成課內已完成實作的證明
- Pantone 被當作 CIE XYZ／CIELAB／ΔE／ICC 主線的科學起點
- TASK-05 缺 OS ICC profile、安裝證據或工作色域設定
- 引用外部考試資訊卻未連至官方文件，或把尚未核定資訊寫成事實
