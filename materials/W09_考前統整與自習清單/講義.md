## 本週學習目標

完成本週後，你應能：

1. 以官方簡章核對三科範圍、題型、時間與應試規則，不依賴轉述或舊截圖。
2. 用自己的作品、量測檔與設定紀錄說明 XYZ、CIELAB／LCh、ΔE00、ICC 與軟打樣的關係。
3. 找出個人證據包中至少三個不可重作的斷點，提出具日期與產出的修復行動。
4. 區分證照複習與本課的傳播能力：考科檢查知識與操作，本課還要證明訊息在接觸點是否成立。

## 這一週在解什麼問題

iPAS 考試在 **2026/11/14（六）**，三科同一天：
科一 09:00–10:15、科二 10:45–12:00、科三 13:30–14:45，各 75 分鐘。

本週要處理兩件事：

1. **本課教過的東西，怎麼對應到考科的評鑑細目**
2. **本課沒教到、或只講到概念層的部分，你要自己補什麼**

第二件事比第一件重要。**本課不是補習班**——
本課的目標是讓你交得出業界看得懂的東西，證照是路上的副產品。
但既然你報了名，該補的缺口要說清楚，不能讓你考完才發現。

## 二之二、五個常見斷點

複習時用自己的檔案逐項檢查。**這五個是交件被退回的前五名**：

1. RGB 有數值卻沒有 profile
2. Lab 有數值卻沒有照明體、觀察者或量測來源
3. ΔE 有數字卻沒有公式版本與比較的兩端
4. 軟打樣有截圖卻沒有目的 profile 與 rendering intent
5. 意象有形容詞卻沒有受眾證據與替代色排除理由

**同儕交換 evidence pack**：只圈出「能從檔案重做判斷」的項目，
不要替對方補猜測。補猜測會讓對方誤以為自己的證據是完整的。

### 主線口頭稽核

用自己的樣本走一遍：

```
CIE XYZ → CIELAB／LCh → ΔE00 → ICC 來源與目的 profile → 軟打樣 → 色域映射決策
```

每個箭頭回答兩題：**輸入是什麼？轉換後失去或改變了什麼？**
Pantone 若出現，放在產業指定與色票溝通層，不放在這條科學推導的起點。

## 三、考試當天的現實問題

- **三科同一天，中間有休息**。科一到科二之間 30 分鐘，科二到科三之間 90 分鐘
- **科目二要用實體色票貼紙**，作答方式與考場設備以官方公告為準
- 攜帶具照片及身分證字號之身分證明文件**正本**
- 「考試通知」於考前 10 天起可列印，考場、座位、應攜物品都在上面

### 獲證條件再確認一次

- 同時報考同級全科：平均 70 分，且每科不低於 60
- 非同時報考：每科皆須達 70
- **單科及格成績自應考日起保留三年**

最後一條代表未通過科目可在成績保留期間補考；獲證仍須滿足當年度簡章列出的全部科目門檻。

## 四、本課接下來要做的事

考完之後，課程進入色彩感知模組（W10–W16）。那段的性質和前九週完全不同：

- 前九週：學一套流程，交出符合規格的證據
- 後七週：**對著你自己印出來的樣本，做觀察、記錄、歸因**

你在 W13 會把自己的設計輸出成實體，然後在 W15 量它、W16 改它再印一次。
整個色彩感知模組的觀察對象，就是那張你自己印的東西。

## 五、TASK-05 的修復單

TASK-05 本週到期。**若缺 profile、安裝證據或工作色域，另附一張修復單**，
逐項寫出：缺什麼檔、補作動作、責任人、完成狀態。

修復單**不取代**原交付物，它只是讓缺口可被追蹤。
交修復單不等於通過，但不交修復單而缺件，連補救的機會都沒有。

## 課堂活動與時間配置

本週共 120 分鐘：15 分鐘說明官方範圍與自我檢核規則、三站各 25 分鐘輪替、20 分鐘完成
個人修復計畫、10 分鐘確認考前行動。三站如下：

1. **口頭證據鏈站**：以自己的資料說明「XYZ → CIELAB／LCh → ΔE00 → ICC 轉換 → 軟打樣」。
2. **科目二操作站**：限時完成色票三屬性排序與意象條件判讀，記錄卡住的步驟。
3. **斷點稽核站**：交換 evidence pack，只圈出無法從檔案重做的主張，不替同學猜資料。

## 學習證據與評量角色

學習證據是三站檢核表、至少三項個人缺口、每項缺口的修復動作／產出／完成日期，以及
一段「色差合格但訊息仍可能失敗」的具體案例說明。自習清單不計分；TASK-05 證據併入
ASSIGN-03，主要供可追溯性與缺口修復檢查。

## 學習工作量

自習清單不計分，本週也不新增交件；TASK-05 證據須在本週完成並自存，W13 隨 ASSIGN-03
繳交。課內 120 分鐘完成範圍確認、三站輪替、修復規劃與考前行動確認；課外建議 2–3 小時分科補弱，先處理官方範圍中
尚無法用自己的資料說明者。考試報名、准考資訊及個人身分文件由學生依官方通知自行確認。

## 本週交付

本週**不收件**——ASSIGN-02 已於 W08 收，下一個交件點是 W13 的 ASSIGN-03。

但本週是 **TASK-05 的證據截止線**：設備借用與校正操作到本週為止，
之後 Block B 的設備時段全部給實體輸出。做完先自存，W13 隨 ASSIGN-03 交。

TASK-05 的完整交付物：顯示器校正紀錄、ICC profile 檔名與版本表、
工作色域設定表、軟打樣設定表、色域外色彩清單、AI 使用揭露。

本週另外發放自習清單（本檔第二節），不列入評量。

## 失敗條件

- TASK-05 缺 ICC profile 紀錄或工作色域設定 → 未通過
- 把 software calibration 寫成硬體校色 → 該段作廢
- 軟打樣設定表無法重現當時畫面 → 該項不採計
- 只列考科名詞，沒有連到自己的檔案、數值或設定紀錄 → 該項不採計
- 把自習清單寫成課內已完成實作的證明 → 該段作廢
- 引用外部考試資訊卻未連至官方文件 → 該主張作廢

## 本週重點整理

1. 考試日期、題型、應攜文件與獲證門檻都要回到當年度官方簡章核對。
2. 複習不是背名詞，而是能用自己的檔案說出每次轉換的輸入、條件與損失。
3. RGB 無 profile、Lab 無條件、ΔE 無公式與兩端、軟打樣無設定，都是不可重作的斷點。
4. 證照是專業知識的檢核；本課更要求把技術證據連回訊息、閱聽人與媒介後果。
