# W11｜色適應、色恆常與對比效應

## 這一週在解什麼問題

閱聽人不會在真空中看顏色。先前看的畫面、周圍背景與觀看時間都會改變下一個色彩訊息。本週用同一組樣本，分開檢查時間性的適應與空間性的背景效應。

## 一、先分兩條因果鏈

- 適應／後像：前一段刺激與時間改變後續判讀。
- 同時對比：當下背景與鄰近顏色改變目標色外觀。

活動分兩輪，不同時改背景與適應光。若兩項一起改，就不能指出哪個條件造成差異。

## 二、色恆常不是永不改變

視覺系統常能在照明改變時維持物體色判斷，但線索不足、光譜特殊、場景割裂或適應不完整時會失效。報告不要寫「人眼會自動校正」；要寫場景提供了哪些照明與物體線索。

CIE 對色覺與色貌的標準化工作可由 [CIE Division 1](https://www.cie.co.at/technical-work/divisions/division1)追查。

## 三、背景實驗

把同一 token 放在淺灰、深灰與一個高彩度背景上。固定尺寸、位置、螢幕、亮度、距離與呈現時間。觀察者依亂序表判斷明暗、偏色方向與訊息層級，不能看到前一人的答案。

若相近色差在特定背景附近更容易被看出，可描述為局部判讀敏感度改變；使用 `crispening` 名詞時要附指定來源與本次操作定義，不把所有對比現象都貼同一標籤。

## 四、P2 累積規則

P2 追加到 P1，不另建一套樣本 ID。每筆加入：前置刺激、適應時間、背景 ID、呈現順序、重複次數、判讀結果與不確定標記。任何事後改碼都保留原值與版本紀錄。

## 本週交付

- P2 適應條件與背景條件表
- 同一 token 在三種背景的亂序判讀紀錄
- 一張「適應效應／背景效應」分流圖，逐筆連到觀察事件 ID
- 一則色恆常成功或失效案例，寫出可見線索與限制

## 失敗條件

- 同一輪同時改變背景、樣本與適應時間，無法辨識差異來源
- 沒有呈現順序、距離或時間紀錄
- 用「人眼不準」取代機制與條件說明
- P2 另建無法回指 P1 的樣本編號
- 把個人偏好寫成色恆常或對比效應證據
