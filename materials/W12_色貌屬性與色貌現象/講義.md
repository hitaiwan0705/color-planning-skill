# W12｜色貌屬性與色貌現象

> **狀態：草案。**

---

## 這一週在解什麼問題

你把打樣拿給客戶，他說：**「這個顏色太重了。」**

「重」是什麼意思？

- 太暗？
- 太鮮豔？
- 面積太大？
- 在那個環境下看起來太突出？

**這四件事的修法完全不同，而且互相衝突**：把它調亮會讓彩度看起來下降，
把彩度降下來又可能讓它在版面上消失。

如果你不能把客戶那句話翻譯成具體的哪一個量，你就只能瞎改。
改三次都沒改對，客戶會覺得你不專業——**問題其實出在第一句話沒有被正確拆解。**

**本週要建立的能力**：把模糊的色彩描述，拆成可以分別記錄、分別修正的欄位。

---

## 一、中文在這裡的詞彙比需要的少

這是實務上真正的難點：**同一個中文詞會對應到好幾個不同的量。**

| 你聽到的詞 | 可能指的是 |
|---|---|
| 「亮」 | 物理上的光強度？還是看起來的明亮程度？還是相對於白的明度？ |
| 「深」 | 明度低？還是彩度高？ |
| 「濃」 | 彩度高？還是墨量多？ |
| 「淡」 | 明度高？還是彩度低？ |

**先建立兩把刀**，其他的都掛在這兩把刀上：

### 第一把：物理量 vs 知覺量

- **物理量**：儀器量得到、有單位。例如光的強度
- **知覺量**：只能問人、沒有單位。例如「看起來多亮」

儀器給你物理量，客戶給你知覺量。**兩者不會自動對應。**

### 第二把：絕對量 vs 相對量

- **絕對量**：燈開得越亮，它就越大
- **相對量**：除以參考白之後的比值，燈變亮它不變

同一張紙，在明亮的房間和昏暗的房間，**絕對量差很多，相對量幾乎不變**。
你在燈箱裡看和在教室裡看，變的是絕對量。

## 二、記錄時要分欄的五個欄位

本課要求在觀察紀錄裡把下列各項**分欄登錄**，不得互相代替：

| 欄位 | 問的問題 | 記錄方式 |
|---|---|---|
| 明度 | 相對於參考白，這個色有多亮 | 相對量表，須註明參考白 |
| 明亮度 | 不管參考白，它看起來多亮 | 絕對感受，須註明環境亮度 |
| 彩度 | 相對於參考白的鮮豔程度 | 相對量表 |
| 飽和度 | 相對於它自己的明亮度，有多鮮豔 | 相對量表 |
| 色相 | 偏向哪個色 | 描述或角度 |

**為什麼要分這麼細**：因為修正動作不同。
明度不足要改的是階調；彩度不足要改的是色料或色域；
飽和度的問題常常是**明度太高把彩度稀釋了**——那時降明度反而讓它看起來更鮮豔。

### 本週的主要失分點

交件時寫「這個色偏深」而不分欄。這種描述無法轉成修正動作，
下一位接手的人看不懂你在說什麼。**逐欄登錄，不接受單一「顏色深淺」帶過。**

## 三、色貌現象：同一組數值，不同的看起來

色貌現象指的是：**XYZ 沒變，但看起來變了。**
以下四類最常在跨媒體工作中出現。

| 現象 | 內容 | 你會在哪裡遇到 |
|---|---|---|
| 環境亮度改變彩度感 | 整體變亮時，顏色看起來更鮮豔 | 展場調亮之後，原本合適的配色變刺眼 |
| 環境亮度改變明暗對比感 | 整體變亮時，明暗對比看起來更強 | 螢幕亮度調高後，暗部細節「跑出來」 |
| 光源色偏影響非中性色 | 中性色被拉走，鮮豔色相對穩定 | 暖光下白紙偏黃但紅色標誌變化不大 |
| 高彩度單色光的色相偏移 | 亮度改變時，感覺到的色相跟著移動 | 舞台燈調光時顏色「跑掉」 |

### 這一節與規範文件的關係

**品牌規範只寫一組數值是不夠的。**
它至少要同時寫出：適用的觀察條件、可接受的偏移範圍、以及不同接觸點的變體規則。

W13 之後你會親自碰到這件事：同一組 token，
在螢幕上、在實體輸出的樣本上、在燈箱不同光源下，是不同的樣子。

> 本節的模型層（色貌模型如何以數學預測這些現象）**不在本課範圍**。
> 本課只到「知道有這些現象、能在紀錄中把它們分開」。
> iPAS 科目三 L13307 只要求概念層，W08 已講；
> 想深入的可循 W09 自習清單。

## 四、P3：色貌屬性分欄記錄

### 這一週要新增什麼

回到你的觀察基底，對每一個色**逐欄登錄五個屬性**，並在兩種環境亮度下各做一次。

| 步驟 | 內容 |
|---|---|
| 1 | 燈箱正常亮度下，五欄逐一登錄 |
| 2 | 降低環境亮度（或改用較暗的觀察環境），重做一次 |
| 3 | 標出哪幾欄改變了、哪幾欄沒變 |
| 4 | 對照儀器數值：數值變了嗎 |

**預期你會發現**：儀器數值幾乎沒變，但你的「明亮度」與「彩度」欄改變了。
這正是色貌現象的直接證據，而且是你自己量出來的。

### 歸因格式（延續 P2）

```
現象：色票 C 在降低環境亮度後，彩度欄由「中」降為「低」，明度欄不變。
歸因：環境亮度改變彩度感（絕對量變化，相對量不變）。
排除：
  - 非光源色偏——兩次皆為 D65
  - 非適應不足——兩次皆停留十分鐘以上
  - 非量測誤差——儀器數值兩次差異在重複量測的離散範圍內
```

## 本週交付

進度交件 **P3**：

- 觀察基底每一色的五欄屬性登錄，在兩種環境亮度下各一份
- 標出哪幾欄改變、哪幾欄未變
- 對應的儀器數值，說明數值是否改變
- 至少兩筆色貌現象的歸因，附排除理由
- AI 使用揭露

## 失敗條件

- 五欄未分開登錄，或以單一描述代替 → 退回重做
- 只做一種環境亮度 → 未達本週要求
- 未附儀器數值對照 → 該筆不採計
- 歸因未附排除理由 → 該筆不採計
