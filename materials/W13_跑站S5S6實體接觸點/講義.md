## 這一週在解什麼問題

螢幕上的品牌色交給另一位操作者輸出後，還能保有原本的辨識、區隔與語氣功能嗎？本週不追求「印得漂亮」，而是驗證規範能否跨越檔案、軟體、輸出設備、媒材與觀看環境，讓下一位操作者重作並指出落差發生在哪一站。

## 本週學習目標

完成本週後，你能：

1. 依訊息目的選定實體接觸點與媒材，而非先被設備型號綁住。
2. 建立可重作的媒材／輸出條件紀錄，交給同學後仍能照表執行。
3. 產生第一次實體輸出，分開記錄「輸出事實」與「觀看判斷」。
4. 將螢幕與實體落差連回辨識、層級、警示或品牌語氣等傳播功能。

## 知識群與關鍵詞

| 知識群 | 關鍵詞 | 本週要回答的問題 |
|---|---|---|
| 接觸點與媒材 | touchpoint、substrate、surface、viewing context | 這個媒材為何適合該閱聽人與使用情境？ |
| 檔案到輸出的色彩鏈 | source profile、output profile、rendering intent、RIP | 哪些設定必須留下，別人才做得回來？ |
| 實體輸出變因 | media white、gloss、opacity、ink limit | 同一組數值為何在不同實體條件下改變？ |
| 跨媒體功能驗證 | recognition、hierarchy、warning、tone | 落差是否已使訊息功能失效？ |

ICC 規範將 perceptual、media-relative colorimetric、saturation 與 ICC-absolute colorimetric 定義為不同的 rendering intents；因此只寫「已轉 CMYK」不足以重作轉換，還要記錄來源與目的描述檔、intent 及軟體版本。[International Color Consortium, ICC.1:2022](https://www.color.org/specification/ICC.1-2022-05.pdf)

## 二、跑站規則與設備前檢查

S5 是「條件登錄」，S6 是「第一次輸出」。每站當場以組別代碼簽核，簽核計入參與；簽核只能證明完成操作，不能代替成果證據。

先寫需求，再選工具：

| 功能需求 | 操作前核對 | 若現場工具不支援 |
|---|---|---|
| 指定尺寸的實體樣本 | 可輸出範圍、媒材厚度、安全規則 | 等比例縮小並記錄比例，或改用可輸出的同類媒材 |
| 指定媒材表面 | 可用媒材、表面處理、固定方式 | 改用光澤與不透明度接近的替代媒材並揭露差異 |
| 指定色彩轉換 | 可用輸出描述檔、RIP 設定 | 使用可取得的描述檔完成比較，限制寫入規範 |
| 特殊打底或表面效果 | 特殊墨層與表面處理能力 | 改用不依賴特殊墨層的版本，不把缺少功能算成學生失敗 |

只有依賴特定功能的那一步需要等待現場核對；需求分析、檔案整理、媒材比較、紀錄表與替代方案可先完成。

若本週使用系上 Mimaki UJF-3042FX，製造商公布的最大印刷範圍為 300 × 420 mm、媒材厚度上限為 50 mm；實際可用墨水、媒材、固定方式與通風安全仍以操作當日核對為準。若設備或必要功能不可用，改用可留下等價檔案、媒材與觀看條件證據的輸出流程，不刪除學習目標。[Mimaki, UJF-3042FX specifications](https://taiwan.mimaki.com/product/inkjet/i-flat/ujf-3042fx/specification.html)

## 三、S5：建立媒材／設備描述檔

輸出前登錄下列欄位：

| 類別 | 必填欄位 |
|---|---|
| 傳播任務 | 訊息目的、目標閱聽人、接觸點、觀看距離與環境 |
| 檔案 | 檔名、版本、尺寸、色彩空間、嵌入的來源描述檔 |
| 轉換 | 目的描述檔名稱與版本、rendering intent、黑點補償設定 |
| 媒材 | 名稱、廠牌／識別、厚度、底色、光澤、不透明度 |
| 輸出 | 設備識別、軟體與版本、模式、解析度、日期、組別代碼 |
| 權利 | 圖像／字型來源、AI 協助揭露、可使用範圍 |

### 交接測試

兩人交換描述檔，在不口頭提示的情況下圈出無法執行或有兩種解讀的欄位。原作者只能根據對方圈出的問題修訂文字，不得用「到時候再說」補足規格。

## 四、S6：第一次輸出與觀察

### 輸出前

1. 對照版本與尺寸，確認不是舊檔。
2. 確認來源描述檔、目的描述檔與 rendering intent。
3. 保存原設定與畫面紀錄；不要覆寫工作檔。
4. 對色域外顏色寫出處理方式與預期後果。

### 輸出後

先編定樣本 ID，再記錄觀看條件，最後才判讀。至少在兩種可重現的光照條件下觀察；若無標準燈箱，可使用兩個可辨識且可重複的光源環境，記錄光源識別、位置、時間、周圍色與觀看距離，不宣稱符合未驗證的標準條件。

| 觀察欄位 | 寫法 |
|---|---|
| 事實 | 樣本 ID、光源、背景、距離、時間 |
| 色貌描述 | lightness、brightness、chroma、saturation、colorfulness；保留英文術語避免混稱 |
| 跨媒體差異 | 與螢幕版本逐項對照，不寫籠統的「有色差」 |
| 功能後果 | 辨識／層級／警示／語氣：維持、失效或證據不足 |
| 初步歸因 | 提出一個最可能機制，並寫出至少一個排除理由 |

## 課堂活動與時間配置

1. 15 分鐘：確認傳播任務、分組、設備安全與替代流程。
2. 15 分鐘：交換 S5 描述檔，完成交接測試。
3. 50 分鐘：依排程完成第一次輸出並保存設定。
4. 25 分鐘：在兩種觀看條件下完成事實與判讀雙欄紀錄。
5. 15 分鐘：回到接觸點對照表，標示功能維持、失效或證據不足並完成離站檢查。

## 本週交付

本週收 ASSIGN-03，並發放 ASSIGN-04。S5、S6 證據留到 W18 隨 ASSIGN-04 一次提交：

- 可由另一位操作者執行的媒材／設備描述檔。
- 第一次輸出樣本與不可覆寫的版本索引。
- 來源／目的描述檔、rendering intent、軟體版本與輸出設定紀錄。
- 兩種觀看條件下的觀察表與螢幕—實體對照。
- 每項傳播功能的維持／失效／證據不足判定。
- 初步機制歸因、排除理由與設備替代方案紀錄。

## 學習證據與評量角色

S5、S6 簽核屬參與證據；上述檔案屬期末 ASSIGN-04 的專業能力證據。ASSIGN-04 在本週發放，評分規準同步公告：

| 向度 | 比例 | 可觀察證據 |
|---|---:|---|
| 共同專業能力：觀察條件紀錄完整性 | 15% | 三接觸點的媒介、光源、距離、時間、色彩空間與輸出設定可重作 |
| 共同專業能力：機制歸因與排除理由 | 20% | 每個失效點有證據支持的主因、排除理由與證據不足標示 |
| 共同專業能力：資料與工具輸出的一致性 | 20% | 原始檔、事件 ID、描述檔、量測／觀察與正文互相對得上 |
| 共同專業能力：限制與風險揭露 | 15% | 設備、媒材、樣本、觀察者與推論邊界及其訊息風險寫明 |
| 差異化反思：個人決策歷程與轉折 | 10% | 指出一項被後續證據推翻的原判斷及原因 |
| 差異化反思：限制辨識與自我評估 | 10% | 說明資料不能支持的主張及避免誤用的方法 |
| 差異化反思：未來情境遷移與具體行動 | 10% | 說明如何把本次方法移轉到另一媒介或傳播任務 |

必要門檻：交付物齊全、AI 使用揭露存在、數值主張可追溯。未達門檻的缺件不能由其他向度補償。

## 學習工作量

- 課內：120 分鐘完成安全確認、交換檢查、輸出、第一次觀察與離站檢查。
- 課外：約 120–180 分鐘整理紀錄、命名檔案及修訂規範。

## 失敗條件

- 缺來源或目的描述檔、intent、版本或觀看條件，導致流程無法重作。
- 只交成品照片，沒有設定檔、樣本 ID 與原始紀錄。
- 以「印壞了」「看起來不對」代替可檢查的差異與機制歸因。
- 把設備缺少某項功能直接寫成作品失敗，卻沒有提出功能等價的替代方案。
- 有跑站簽核但交不出該站產出，或用後來結果反推補寫當時條件。

## 本週重點整理

1. 媒材、輸出設定與觀看環境都是訊息的一部分，不是製作附件。
2. 色彩轉換必須記錄來源／目的描述檔與 rendering intent，才能交接與重作。
3. 第一次輸出的任務是產生可觀察、可量測、可修正的實體證據。
4. 設備未確定只影響依賴該功能的操作，不阻擋需求、方法與替代方案設計。
