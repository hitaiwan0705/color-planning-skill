# W15｜設備站 S7–S8：燈箱觀察與儀器量測

## 這一週在解什麼問題

第一次輸出已經存在，現在要把「偏了」變成可重做的判斷。S7 記錄人眼在指定照明下看到什麼；S8 記錄儀器在指定條件下量到什麼。兩條證據並排，才足以決定下一週改哪裡。

## 一、S7 標準燈箱觀察

每次觀察登錄樣本 ID、D50 或 D65 模式、背景、方向、距離、適應時間、呈現順序、觀察者匿名代碼與判讀。燈箱型號與等級一律填「待核對」，不從按鍵標籤推定。

## 二、判斷任務的四個參數

| 參數 | 本週最低紀錄 |
|---|---|
| 觀察者 | 匿名代碼與人數，不收姓名學號 |
| 順序 | 隨機或平衡方式、實際順序 |
| 重複 | 每個關鍵配對至少兩次 |
| 參考 | 指定參考樣本與參考條件 |

本週是課堂品質檢查，不是研究資料蒐集。`research_overlay` 仍為 false；不得把同學紀錄另作研究分析。

## 三、S8 i1 Pro 量測

沿用 W06 的事件 ID 規則，以 i1 Pro 2／3 量參考樣本與第一次輸出。每點保留原始檔、重複讀值、L\*a\*b\* 與 `ΔE00 (CIEDE2000)`。視覺觀察與儀器結果分欄，不為了讓兩者一致而刪除資料。

CIEDE2000 版本依 [ISO/CIE 11664-6:2022](https://www.cie.co.at/publications/colorimetry-part-6-ciede2000-colour-difference-formula-1)註記。

## 四、P6 修正決策表

每個候選修正寫：偏移位置、儀器證據、人眼證據、訊息後果、最可能機制、排除理由、要改的變項與預期效果。若兩條證據衝突，保留衝突並降低結論強度。

## 本週交付

- P6 D50／D65 視覺觀察表與完整任務參數
- i1 Pro 原始量測檔、條件表與 ΔE00 報告
- 視覺—儀器成對對照表，每筆連到樣本與事件 ID
- 一張修正決策表，逐項寫出訊息後果與預期效果
- W16 設備時段與檔案版本確認單

## 失敗條件

- 燈箱紀錄沒有模式、背景、距離或適應時間
- 燈箱型號／等級寫成已確認，或使用未確認螢光燈管
- 觀察者紀錄含姓名或學號
- ΔE00 沒有原始量測檔、條件或 CIEDE2000 版本
- 只因人眼與儀器不一致就刪除其中一條證據
