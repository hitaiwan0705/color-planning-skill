# W17｜自主學習（不排課）

> **狀態：草案。** 本週不排課。授課者提供固定 office hour。

---

## 這一週在解什麼問題

前十六週你一直在回答別人設定的問題。這兩週要換一件事：

> **你自己提一個問題，然後用你手上的資料回答它。**

這是 TASK-08 的全部內容。它不是心得，不是總結，是一份**小型的研究報告**。

---

## 一、你手上已經有什麼

七週的進度交件累積出來的東西比你以為的多：

| 資料 | 來源 |
|---|---|
| 同一組色在不同光源下的判讀 | P2、P6 |
| 同一組色在不同背景下的判讀 | P2 |
| 同一組色在不同適應狀態下的判讀 | P2 |
| 五欄色貌屬性，在兩種環境亮度下 | P3 |
| 螢幕判讀 vs 實體判讀的對照 | P4 |
| 色覺差異與灰階情境的可區辨性 | P5 |
| 儀器數值與人眼判讀的完整對照 | P1–P7 |
| 修正前後的對照 | P7 |

**這是一份真實的資料集**，不是習題答案。TASK-08 就是用它回答一個問題。

---

## 二、什麼樣的問題可以問

好問題的判準只有一個：**能被你手上的資料回答。**

| 可以問 | 為什麼 |
|---|---|
| 「哪一種機制最常造成我的判讀與儀器不一致？」 | 資料裡有歸因紀錄 |
| 「背景改變對我的明度判讀影響多大？」 | P2 有三種背景 |
| 「我的品牌主色在哪個接觸點最不穩定？」 | P4、P6 有跨媒介對照 |
| 「我七週來的歸因準確率如何變化？」 | P7 要求標出被推翻的歸因 |

| 不要問 | 為什麼 |
|---|---|
| 「色彩心理學對品牌的影響」 | 你沒有這方面的資料 |
| 「哪一種配色最好看」 | 沒有可觀察的判準 |
| 「消費者偏好哪個顏色」 | 你沒有做消費者研究 |

**問題太大是最常見的失敗。** 一個能被七週資料回答的小問題，
勝過一個需要另做研究的大問題。

## 三、報告的結構

五節，缺一不可：

| # | 節 | 內容 | 常見錯誤 |
|---|---|---|---|
| 1 | 問題 | 一句可由附件資料回答的問題 | 寫成主題而非問題 |
| 2 | 情境 | 訊息、媒介、閱聽人與色彩角色 | 跳過，直接進技術細節 |
| 3 | 方法 | 樣本、觀察條件、工具／儀器、程序與版本 | 只寫「觀察與量測」，沒寫條件 |
| 4 | 結果 | 表格或圖，**逐筆連到原始事件 ID** | 只放結論不放資料 |
| 5 | 解釋 | 最有證據的機制與排除理由 | 列多個機制卻不排除 |
| 6 | **限制** | 樣本、觀察者、設備、條件與推論邊界 | **留白或寫「無」** |
| 7 | 設計後果 | 這個結果會改變哪條色彩規則、不會改變什麼 | 只寫「有幫助」 |
| 8 | 附件 | 來源、AI 使用揭露與附件索引 | 缺索引，附件找不到 |

第 2 與第 7 節是這份報告和純技術記錄的分界：**它要說的是這件事對傳播的後果**，
不只是「數值差了多少」。

### 限制章節不得為空

這是本課最硬的一條要求。理由：

- 你的觀察者可能只有你一個人 → 不能推論到「一般人」
- 你的樣本只有一種媒材 → 不能推論到其他媒材
- 你的燈箱型號待核對 → 不能宣稱符合某等級的觀察條件
- 工具的參照涵蓋率 7/34 → 不能宣稱研究等級的驗證

**寫出限制不會扣分，隱瞞限制會。**
一份誠實說明自己能力邊界的報告，比一份過度宣稱的報告有用得多。

## 四、這一週怎麼用

| 時段 | 建議 |
|---|---|
| 前半 | 把 P1–P7 的資料整理成一張表，看看哪裡有 pattern |
| 中段 | 從 pattern 裡挑一個問題，寫成一句話 |
| 後半 | 檢查：這個問題真的能被這份資料回答嗎？不行就換一個 |

**Office hour 的正確用法**：帶著「我想問這個問題，但我不確定資料夠不夠」來，
而不是帶著「我不知道要寫什麼」來。
