## 一之二、錄製口頭發表

發表是這學期的最後一個接觸點。前面十七週你都在對儀器和檢核器交代，
最後要對**人**交代。

### 講什麼

不要複述做過的步驟。講三件事：

1. **你要傳的訊息是什麼**，在哪三個接觸點上
2. **哪一項功能掉了**，為什麼掉，你怎麼知道不是別的原因
3. **你的規範書擋得住什麼、擋不住什麼**——第三項最有價值，也最常被跳過

### 不要做的事

- 不要把限制藏起來。**「這個色在混合照明的展場會失去區隔功能」講出來，比假裝沒問題有用得多。**
- 不要用「感覺比較好」作結論。這學期每一句判斷都要有證據，最後一句也一樣。
- 不要逐字念投影片；用口語說明投影片與原始證據的關係。

### 提交前四次核對

| 核對 | 問什麼 |
|---|---|
| 可重作 | 報告中的數值能回指原始檔、公式版本與條件嗎 |
| 可閱讀 | 圖表標題、單位、樣本 ID、圖例與替代文字齊全嗎 |
| 可交接 | 九站索引指出每一站的檔案與版本了嗎，缺項有誠實列出嗎 |
| 可使用 | 外部來源、AI 協助、作品／圖片權利**三份分開**揭露了嗎 |

**課堂交件不等於同意公開或研究使用。** 研究 overlay 仍為關閉；
問卷、訪談、研究分析或公開展示須另依知情同意與作品授權處理，且不影響成績。

### 為什麼要交原始資料而不只交報告

因為報告是你的詮釋，原始資料才是證據。
兩者都交，別人才能判斷你的詮釋是否成立——**這正是本課從第一週講到最後一週的事**。

## 二、交件前的自我檢查

逐條打勾，任一項為否就先不要交：

- [ ] 問題是一句話，而且具體到可以被資料回答
- [ ] 每個數值主張都追溯得到工具輸出或儀器量測檔
- [ ] 外部事實都附了可查證來源；查不到的標記為未查證，沒有寫成肯定句
- [ ] 限制章節寫出了至少三項這份資料**不能**回答的事
- [ ] 沒有引用未標示可信度等級的非官方筆記作為判準
- [ ] AI 使用揭露完整，且沒有把 AI 生成內容當作事實來源
- [ ] 原始資料檔齊全，不是只有整理後的表

本課的評分先過門檻、再算權重：

## 四、最後一件事

這門課從頭到尾在講同一件事：

> **顏色的主張，要有證據；證據，要能被別人重算出來。**

你交出去的每一份檔案——design token 表、量測條件表、ΔE00 報告、
觀察紀錄、修正紀錄——都是為了讓下一個人接得住。

那個人可能是印刷廠的技師、下學期的專題組員、三年後的你自己，
或是一個你從沒見過、但要靠你的規範做出實體的供應商。

**能被接住的顏色，才是被規劃過的顏色。**

## 失敗條件

- 問題無法由所附資料回答 → 未通過
- 限制章節為空 → 未通過
- 以文獻敘述替代自身觀察資料 → 未通過
- 將 AI 生成內容列為事實來源 → 未通過
- 只交報告未交原始資料檔 → 未通過
- 數值主張無法追溯至工具輸出或量測檔 → 該主張不採計
- 提交資料夾含姓名、學號或其他直接識別資訊 → 立即退回
- 原始資料遭覆寫，或只交整理後表格 → 未通過
- 缺簡報檔或錄製的口頭發表 → 交付物不齊，未通過
- 以簡報或錄影代替證據交付 → 未通過；簡報是說明，不是證據
- 將學習問卷未填列為缺交或扣分 → 違反自願、不計分原則
